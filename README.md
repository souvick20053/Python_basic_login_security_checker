# Login Security Checker 🔐

A simple Python-based login security checker project.

## Features

- Takes username and password as input
- Checks whether the username is correct
- Checks whether the password is correct
- Shows "Access Granted" when both are correct
- Shows which credential is correct or incorrect
- Uses a loop for repeated login attempts
- Uses 'break' to stop to loop after successful login
- Uses the `time` module for delay

## Technologies Used

- Python
- if-else
- and operator
- while loop
- break statement
- time module
- input/output

## Purpose

This project was created for practicing Python conditional statements, loops, and basic cybersecurity login logic.

## Note

This is a beginner-level practice project and is not intended for real-world authentication.
